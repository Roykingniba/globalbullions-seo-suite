What is a WordPress MCP server?

A WordPress MCP server is a connection point that lets an AI assistant use your site directly. MCP (Model Context Protocol) is the open standard that Claude, ChatGPT, Cursor and other assistants use to connect to outside tools. Once your site is an MCP server, the assistant can read your content and carry out admin tasks itself, instead of telling you which buttons to click.

KAI MCP is a WordPress plugin that adds that server to your site. It is served by WordPress itself at https://yoursite.com/wp-json/kai-vibe/v1/mcp. There is no third-party service in the middle and no account with us is needed to run it: your site talks straight to the assistant you choose.

How to connect WordPress to Claude or ChatGPT with KAI MCP

Setup takes about five minutes and needs no code, API key or configuration file.

  1. Install the plugin

    Download the zip from this page. In wp-admin go to Plugins, Add New, Upload Plugin, choose the zip, then Install Now and Activate. It appears in your dashboard menu as KAI Vibe.

    Your site must use HTTPS. The plugin refuses connections over an unencrypted link, because a key would be readable in transit. Most hosts include a free SSL certificate.

  2. Copy your website address for AI

    Open KAI Vibe, Connect. The top box shows one line, your site's MCP address. Press Copy. That line is everything the assistant needs.

  3. Add it to your assistant

    Claude

    Settings, then Connectors, then Add custom connector. Give it any name and paste the address into the URL box.

    ChatGPT

    Settings, then Connectors, and add one. Paste the address as the server URL and choose OAuth if it asks. Connectors are not on every ChatGPT plan.

    Claude Code

    Run claude mcp add --transport http kai-vibe https://yoursite.com/wp-json/kai-vibe/v1/mcp, then /mcp and choose to authenticate.

    Cursor, VS Code, Windsurf, n8n

    Add the address to the app's MCP settings. The Connect screen shows the exact block to paste for each one.

  4. Press Connect in WordPress

    Your assistant opens a WordPress page asking you to approve it. Log in as the account it should act as and press Connect. It tells you in plain words what the connection can and cannot do before you agree.

  5. Ask for what you need

    Talk to it the way you would talk to a colleague. You do not need to know any commands.

    • "Draft a blog post about our new opening hours and match the style of my last three posts."
    • "The About page looks broken. Work out why and fix it."
    • "Find every page that still mentions our old phone number and update it."
    • "Put every product in the Seeds category on a 10% sale and list the ones that are out of stock."
    • "Add alt text to every image that is missing it."
    • "Give me a health check of this site and tell me what to worry about."

What the assistant can do on your WordPress site

Posts and pages

Find, create, edit, duplicate and schedule posts, pages and custom post types. New posts are saved as drafts unless you ask for them to be published. Custom fields, revisions and restore are included.

Page builders

Elementor, Divi, Beaver Builder, Bricks, Breakdance, Oxygen and WPBakery layouts are read and written in their own format, then the builder cache is cleared, so designs do not break.

WooCommerce

Search products, change prices, sale prices and stock, look up orders, update order status and pull sales reports. Everything goes through WooCommerce's own functions, so totals stay correct.

Media

Upload images from a link, set featured images, search the library, find images with no alt text and fill it in.

Site structure

Menus, categories, tags and custom taxonomies, comments and replies, and user accounts and roles.

Search and replace

Search across all content, preview a replacement as a dry run, then apply it once you approve.

Fixing and housekeeping

Site health checks, the error log, how a page actually renders, caches, permalinks, scheduled tasks, and plugins or themes that need updating.

For developers

Theme and plugin files, database queries and WP-CLI. WP-CLI and database writes are switched off by default in Settings, and file edits always wait for your approval.

Is connecting AI to WordPress safe?

It is as safe as the limits you set, and KAI MCP is built around those limits. The assistant can never do more than the WordPress account that approved it, risky actions stop and wait for you, and anything it changes can be put back.

Risky actions wait for your approval

Permanently deleting posts, media, users or comments, installing, activating or removing plugins, switching themes, editing files, changing site settings, changing an order's status and search-and-replace across the site all stop in an approval queue. Approving one lets the assistant do that exact action once. Anything else needs a fresh approval.

One-click undo for every change

Every change is stored with a copy of what was there before, including things WordPress revisions do not cover: custom fields, settings, categories and theme files. Press Undo on the Changes screen to put it back.

You choose exactly what each key can do

Give each person or app its own key, pick the WordPress account it acts as, set an expiry date, and tick only the jobs it needs. Presets for Read only, Content editor and Developer make this quick. Point it at an Editor account and it cannot install a plugin, whatever it is asked.

A full record of everything it did

The Activity screen logs every action with the time, the key, the WordPress user and the result. Values that look like passwords or API keys are removed before they are written.

Nothing goes through us

No middleman, no analytics, nothing phoned home. Your content only goes to the assistant you connect, and only when you ask it something.

Secrets stay hidden

Passwords are never readable, settings that look like keys are hidden, and your site address, admin email and registration settings cannot be changed this way.

Off switch

Disconnect any assistant from the Tokens screen, or switch all connections off with one tick box. Deleting the plugin removes every key and all of its data.

Works with the AI tools you already use

Any app that supports MCP can connect, including Claude, ChatGPT, Claude Code, Cursor, VS Code, Windsurf and automation tools such as n8n. Apps sign themselves in with OAuth, so there is nothing product-specific to set up and you can switch assistants without touching the site. For the few tools that can only read a fixed key from a settings file, you can create a key by hand.

KAI MCP or the WordPress MCP Adapter?

The WordPress MCP Adapter is a developer building block: it exposes "abilities" that plugins register through the WordPress Abilities API, and a developer decides what to expose and how clients connect. It is a good fit if you are building your own integration.

KAI MCP is a finished plugin for site owners. It ships with 89 ready tools, including page builder and WooCommerce support, and adds what a live site needs around them: a two-button OAuth connection, an approval queue, one-click undo and an activity log.
