What a UUID is for

A UUID is a 128-bit identifier written as 32 hexadecimal characters. The point is that you can generate one anywhere, with no central authority handing out numbers, and still be confident nobody else will generate the same one.

Version 4 UUIDs, which this tool produces, are almost entirely random. The odds of a collision are so small that in practice you can ignore them.

They are random, not secret. A UUID is fine as an identifier but should not be used as a password, a session token or an access key on its own.

They also sort poorly. Because version 4 UUIDs are random, using one as a primary key in a database can hurt insert performance on large tables. If that matters to you, look at UUID version 7, which sorts by time.
