What actually makes a password strong

Length matters far more than complexity. A long password made only of lowercase letters beats a short one stuffed with symbols. If you have to choose, choose longer.

  • Use a different password everywhere. The most common way accounts get taken over is a password reused from a site that was breached, not one that was guessed.
  • Use a password manager. Generating a strong password is the easy part. Remembering forty of them is not, and that is what pushes people back into reuse.
  • Turn on two-factor authentication where you can. It protects the account even if the password does leak.
  • Tick the look-alike option if you will have to read the password off a screen and type it somewhere else, since a capital O and a zero are easy to confuse.

These passwords are generated with the operating system's cryptographic random source, not a predictable one. They are not written to disk or kept in any log, but if you are cautious about generating passwords on any website, that instinct is a reasonable one. Your password manager can generate them locally instead.
