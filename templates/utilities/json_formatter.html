The mistakes that break JSON most often

  • A trailing comma after the last item. JavaScript tolerates it, JSON does not.
  • Single quotes. JSON requires double quotes around both keys and string values.
  • Unquoted keys. {name: "x"} is JavaScript, not JSON. It has to be {"name": "x"}.
  • Comments. JSON has no comment syntax, so a // line will fail.
  • Smart quotes. Copying JSON out of a word processor or a chat app often replaces straight quotes with curly ones, which look almost identical but are not valid.

When something fails, the error above names the line and column, so start there.
