What Base64 is, and what it is not

Base64 rewrites data using only 64 safe characters, so it can travel through systems that expect plain text. It is how images get embedded directly in HTML and CSS, and how binary attachments move through email.

Base64 is not encryption. Anyone can decode it in seconds, including with this page. It hides nothing. Never use it to store passwords, API keys or anything else that needs to stay private.

Encoded output is about a third larger than the input, which is why embedding a large image as Base64 can make a page slower rather than faster.
